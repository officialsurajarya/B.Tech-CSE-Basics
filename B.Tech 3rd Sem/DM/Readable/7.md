Chapter 7 introduces **Graph Theory**, a fundamental area of discrete mathematics used to model pairwise relations between objects. Here is a detailed breakdown of the definitions, theorems, and graph classifications covered in this chapter.

### **Basic Definitions in Graph Theory**
A **graph** $G(V, E)$ consists of a set of objects called **vertices** $V = \{v_1, v_2, v_3 \dots v_N\}$ and a set of **edges** $E = \{e_1, e_2, e_3 \dots e_n\}$. Each edge connects an unordered pair of vertices, which are called the **end vertices** of that edge.

*   **Adjacent Vertices:** If two vertices are connected by the same edge, they are considered adjacent. 
*   **Adjacent Edges:** If two different edges meet at (are incident on) the same vertex, they are adjacent edges.
*   **Self-Loop:** An edge that originates and terminates on the exact same vertex $(v_i, v_i)$.
*   **Parallel Edges:** When a single pair of vertices is connected by more than one edge.

### **Degree of a Vertex and Hand-Shaking Theorem**
The **degree of a vertex** $deg(v_i)$ in an undirected graph refers to the total number of edges associated with it.

*   **Hand-shaking Theorem:** Every edge connects two vertices, meaning it contributes a value of 2 to the sum of all degrees in the graph. Therefore, the sum of the degrees of all vertices is always exactly twice the number of edges: $\sum d(v_i) = 2|E|$.
*   A corollary of this theorem is that **the number of vertices possessing an odd degree in any graph is always an even number**.

### **Types of Graphs**
Graphs are classified based on their structural properties:
*   **Complete (or Full) Graph ($K_n$):** A simple graph where every single vertex is directly connected to every other vertex. The total number of edges in a complete graph is calculated as $\frac{n(n-1)}{2}$.
*   **Regular Graph:** A graph where every vertex has the exact same degree (e.g., a "3-regular graph" means every vertex has a degree of 3).
*   **Bi-partite Graph:** A graph where the vertex set can be split into two disjoint sets ($V_1$ and $V_2$), such that every edge only connects a vertex from $V_1$ to a vertex in $V_2$.
*   **Complete Bi-partite Graph ($K_{m,n}$):** A bi-partite graph where every vertex in the first subset is connected to every vertex in the second subset.
*   **Cycle Graph ($C_n$):** A graph comprising a single closed chain of vertices (minimum 3). Every vertex in a cycle graph has a degree of exactly 2, and the number of edges equals the number of vertices.
*   **Wheel Graph ($W_n$):** Created by taking a cycle graph and connecting a single "universal vertex" to all the vertices in the cycle.

### **Representing Graphs in Memory**
Graphs can be stored in computer memory using different data structures based on operational needs:
*   **Adjacency Matrix:** A 2D array of size $V \times V$. If an edge exists between vertex $i$ and vertex $j$, the slot $adj[i][j]$ is marked as 1 (or with the weight $w$ for weighted graphs). For undirected graphs, this matrix is always symmetric.
*   **Adjacency List:** An array of lists where each entry $array[i]$ stores a list of all vertices adjacent to the $i$-th vertex.
*   **Incidence Matrix:** A 2D array representing vertices and edges ($n \times m$). A matrix entry $b_{i,j} = 1$ if edge $e_j$ is connected to vertex $v_i$, and $0$ otherwise. 

### **Complement of a Graph**
The complement of a graph $G$, denoted as $G^c$, has the exact same vertex set as $G$. However, an edge exists between two vertices in $G^c$ **if and only if** there is no edge between them in the original graph $G$. 
*   **Properties:** Combining a graph and its complement yields a complete graph ($G \cup G^c = K_n$), while their intersection is a null graph ($G \cap G^c = \Phi$). Furthermore, $|E(G)| + |E(G^c)| = \frac{n(n-1)}{2}$.

### **Planar Graphs and Euler's Formula**
A **Planar Graph** is one that can be drawn on a flat 2D plane without any of its edges crossing over each other. 
*   **Non-Planar Graph Examples:** The simplest non-planar graphs are **Kuratowski’s cases**: $K_5$ (a complete graph with 5 vertices) and $K_{3,3}$ (a complete bi-partite graph). If you remove just one edge or vertex from these, they become planar.
*   **Euler's Formula:** For a finite, connected, planar graph, the relationship between regions/faces ($r$), edges ($e$), and vertices ($v$) is defined as: $r = e - v + 2$.

### **Graph Coloring**
*   **Proper Vertex Coloring:** Assigning colors to vertices such that no two adjacent vertices share the same color.
*   **Chromatic Number ($\chi(G)$):** The minimum number of colors needed to achieve a proper vertex coloring.

### **Traversals: Walks, Paths, and Circuits**
*   **Walk:** A finite alternating sequence of vertices and edges. If it starts and ends at the same vertex, it is a **closed walk**; otherwise, it is an **open walk**.
*   **Path:** An open walk where no vertex appears more than once.
*   **Connected Graph:** A graph is connected if there is at least one path between every single pair of vertices. *Example Property:* A graph with $n$ vertices requires a minimum of $n - 1$ edges to be connected.

### **Euler and Hamiltonian Graphs**
*   **Euler Graph:** A connected graph is considered an Euler graph if it contains a closed walk that traverses **every single edge** exactly once. A graph is only an Euler graph if all of its vertices have an even degree.
*   **Hamiltonian Graph:** A graph containing a closed walk that visits **every single vertex** exactly once (before returning to the start). Determining if a graph is Hamiltonian is notoriously a computationally hard (NPC) problem.
