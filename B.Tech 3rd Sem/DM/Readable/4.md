Chapter 4 explores the mathematical concept of **Functions**, detailing their properties, classifications, and operations. Here is a comprehensive breakdown of the concepts and examples provided in this chapter.

### **Definition of a Function**
A function is a specific type of mathematical relation between two sets. It is defined as a relation where **each element of a first set (A) is mapped to exactly one unique element of a second set (B)**. The set of elements in B that are mapped to is known as the **range** of the function. 

*   **Example of what is NOT a function:** Let set $X = \{1, 2, 3, 4, 5\}$ and set $Y = \{2, 3, 4, 5, 6, 7\}$. If we have a relation between X and Y where the element `5` from set X maps to more than one element in set Y, or if an element in set X does not participate in the relation at all, it is considered a valid relation but **not a valid function**.
*   **Counting Functions:** If set A has $m$ elements and set B has $n$ elements, the total number of possible functions from A to B is calculated as $n^m$.

### **Function Composition**
**Function composition** is an operation that takes two existing functions, $f$ and $g$, and combines them to produce a new function $h$, such that $h(x) = g(f(x))$. This means you apply function $f$ to $x$ first, and then apply function $g$ to that result. Like relations, the composition of functions always follows the **associative property**: $f \circ (g \circ h) = (f \circ g) \circ h$.

*   **Example of Composition:** Given two functions defined on finite sets:
    $f = \{(1, 3), (2, 1), (3, 4), (4, 6)\}$
    $g = \{(1, 5), (2, 3), (3, 4), (4, 1), (5, 3), (6, 2)\}$
    The composed function $g \circ f$ (meaning $g(f(x))$) evaluates to: $\{(1, 4), (2, 5), (3, 1), (4, 2)\}$.

### **Types of Functions**
Functions are classified based on how elements in the domain map to the codomain:

**1. One-to-One (Injective Function)**
An injective function maps distinct elements of its domain to distinct elements of its codomain, meaning no two elements in set A point to the same element in set B. 
*   **Conditions:** This type of function is only possible if the number of elements in A is less than or equal to B ($|A| \le |B|$). 
*   **Counting:** The number of possible injective functions is $P(n, m)$. If both sets have the exact same number of elements ($|A| = |B| = n$), the number of possible functions is $n!$.

**2. Onto (Surjective Function)**
A function is surjective if every single element in set B is mapped to by at least one element in set A. This means the **range of the function is equal to set B**. Multiple elements in A can map to the same element in B, as long as no element in B is left unmatched.
*   **Conditions:** This is only possible if the number of elements in B is less than or equal to A ($|B| \le |A|$). Note that if $|A| = |B|$, every onto function is inherently also a one-to-one function.
*   **Counting Formula:** The number of possible onto functions from A to B is calculated using the formula: $n^m - nC_1(n-1)^m + nC_2(n-2)^m - nC_3(n-3)^m + \dots$.

**3. Bijective Function**
A bijection (or one-to-one correspondence) occurs when a function is **both one-to-one and onto**. Every element of the first set is paired with exactly one element of the second set, and vice versa, leaving absolutely no unpaired elements.
*   **Conditions:** A bijection is only possible if the cardinality of both sets is identical ($|A| = |B|$).
*   **Counting:** The number of possible bijections from A to B is $n!$.

### **Inverse of a Function**
An inverse function (or anti-function) essentially "reverses" the original function. If applying function $f$ to $x$ yields $y$, then applying the inverse function $f^{-1}$ to $y$ yields $x$. 
*   **Conditions:** An inverse function $f^{-1}$ **only exists if the original function $f$ is a bijection**.
*   **Example:** If a function is defined as $f(x) = 5x - 7$, its inverse function is evaluated algebraically as $f^{-1}(y) = \frac{y + 7}{5}$.
