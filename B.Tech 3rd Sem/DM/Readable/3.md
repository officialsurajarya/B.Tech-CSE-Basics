### **POSET and Hasse Diagrams**
To make studying partial order relations easier, they are converted into a more convenient graphical representation known as a **Hasse Diagram**. Named after Helmut Hasse, this mathematical diagram represents a finite partially ordered set through its transitive reduction. 

**Steps to Convert a Partial Order Relation into a Hasse Diagram:**
1. Draw a vertex for each element in the set.
2. If a relation `(a, b)` exists in `R`, draw an edge from `a` to `b`.
3. Remove all **Reflexive** (self-loop) and **Transitive** edges.
4. Remove the direction of the edges and arrange them in increasing order of heights.

**Examples for Hasse Diagram Conversion:**
*   Converting explicit relations such as: `R = {(1,1), (1,2), (1,4), (1,8), (2,2), (2,4), (2,8), (4,4), (4,8), (8,8)}` and `R = {(1,1), (1,2), (1,3), (1,6), (2,2), (2,6), (3,3), (3,6), (6,6)}`.
*   Drawing the Hasse diagram for ordered sets defined by the relation "**x divides y**", using sets like `A = (1, 2, 3, 4, 6, 8, 9, 12, 18, 24)` and `A = (2, 3, 6, 12, 24, 36)`.

### **Lattices**
A Hasse diagram or partial order relation is considered a **Lattice** if there exists a **Join** and a **Meet** for every pair of elements. Alternatively, it can be defined as a structure that is both a Join Semi Lattice and a Meet Semi Lattice.

**Laws Governing Lattices:**
Lattices follow several foundational mathematical laws:
*   **Idempotent law**: `A ∨ A = A` and `A ∧ A = A`.
*   **Associative law**: `(A ∨ B) ∨ C = A ∨ (B ∨ C)` and `(A ∧ B) ∧ C = A ∧ (B ∧ C)`.
*   **Commutative law**: `A ∨ B = B ∨ A` and `A ∧ B = B ∧ A`.
*   **Distributive law**: `A ∨ (B ∧ C) = (A ∨ B) ∧ (A ∨ C)` and `A ∧ (B ∨ C) = (A ∧ B) ∨ (A ∧ C)`.
*   **De Morgan’s law**: `(A ∨ B)C = AC ∧ BC` and `(A ∧ B)C = AC ∨ BC`.
*   **Identity law**: `A ∨ ɸ = A`, `A ∧ ɸ = ɸ`, `A ∨ U = U`, and `A ∧ U = A`.
*   **Complement law**: `A ∨ AC = U`, `A ∧ AC = ɸ`, `UC = ɸ`, and `ɸC = U`.
*   **Involution law**: `((A)C)C = A`.

### **Types of Lattices and Boolean Algebra**
Lattices are further classified based on their elements and complement properties:
*   **Unbounded Lattice**: A lattice possessing an infinite number of elements.
*   **Bounded Lattice**: A lattice with a finite number of elements, meaning there will always be a defined upper and lower bound in the lattice.
*   **Complement of an element**: If two elements, `a` and its complement `ac`, exist in a lattice, they must satisfy the equations: `a ∨ ac = Upper bound of lattice` and `a ∧ ac = Lower bound of lattice`.
*   **Distributive Lattice**: A lattice where every element has **at most one** complement (either zero or one).
*   **Complement Lattice**: A lattice where every element has **at least one** complement (one or more).
*   **Boolean Algebra**: A lattice is classified as a Boolean Algebra if it is both complemented and distributed. In other words, every element in the lattice has **exactly one** complement.
