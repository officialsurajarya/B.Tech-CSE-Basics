Chapter 6 explores **Algebraic Structures**, particularly focusing on **Group Theory**. Group theory is a crucial mathematical tool used to estimate the strength of a set with respect to an operator, helping researchers identify the correct mathematical systems for complex problems.

Here is a detailed breakdown of the definitions, properties, and structural hierarchies covered in this chapter.

### **Fundamental Properties of Binary Operations**
To define different algebraic structures, we first evaluate a non-empty set $A$ and a binary operation $*$ based on five key properties:
1.  **Closure Property**: A set $A$ is closed with respect to $*$ if applying the operation to any two elements in the set yields a result that is also in the set. ($\forall a, b \in A, a*b \in A$).
2.  **Associative Property**: The operation does not depend on how the elements are grouped. ($\forall a, b, c \in A, a*(b*c) = (a*b)*c$).
3.  **Identity Property**: There exists exactly one unique element $e$ in the set such that operating any element $a$ with $e$ leaves $a$ unchanged. ($a*e = e*a = a$).
4.  **Inverse Property**: For every element $a$, there exists a unique inverse element $a^{-1}$ within the same set such that operating them together yields the identity element $e$. ($a*a^{-1} = a^{-1}*a = e$). Notably, the identity element is its own inverse, and no two elements can share the same inverse.
5.  **Commutative Property**: The order of the operands does not change the result. ($\forall a, b \in A, a*b = b*a$).

### **Hierarchy of Algebraic Structures**
Based on which of the above properties a set and its operation satisfy, they form different algebraic structures:
*   **Algebraic Structure**: Satisfies only the **Closure** property.
*   **Semi-Group**: Satisfies both **Closure** and **Associative** properties.
*   **Monoid**: Satisfies **Closure**, **Associative**, and **Identity** properties.
*   **Group**: Satisfies **Closure**, **Associative**, **Identity**, and **Inverse** properties.
    *   *Rules of a Group*: In any group, the cancellation law holds good (e.g., $a*b = a*c \rightarrow b = c$) and the inverse of a combined operation flips the order: $(a*b)^{-1} = b^{-1}*a^{-1}$.
*   **Abelian Group**: A group that also satisfies the **Commutative** property.

**Finite Groups and Modulo Operators**
A group with a finite number of elements is a **finite group**, and the number of elements it contains is called its **Order**, denoted as $O(G)$. Because it is difficult to design finite groups using standard addition or multiplication without violating the closure property, **Modulo** operators are used:
*   **Addition Modulo ($+m$)**: $a +_m b = a + b$ (if $a+b < m$), else $a + b - m$.
*   **Multiplication Modulo ($*m$)**: $a *_m b = a * b$ (if $a*b < m$), else $(a * b) \% m$.
*   *Examples evaluated as groups:* Sets like $\{0,1,2,3\}$ with $+_4$ or $\{1,2,3,4\}$ with $*_5$. 

### **Subgroups and Cosets**
*   **Subgroup**: If a subset of a group is also a valid group itself under the same operation, it is a subgroup. The identity element of a group and its subgroup is always identical. Additionally, the intersection of two subgroups always forms another subgroup.
*   **Lagrange’s Theorem**: A foundational theorem stating that the order of a group is always exactly divisible by the order of its subgroup.
*   **Cosets**: Let $H$ be a subgroup of $G$ and $a \in G$. A **left coset** is the set $aH = \{ah | h \in H\}$, and a **right coset** is $Ha = \{ha | h \in H\}$. If you take the union of all distinct cosets of $G$, you will reconstruct the entire group $G$. 
    *   *Example:* For the group $(Z, +)$ and subgroup $H = 3Z = \{ \dots, -3, 0, 3, 6, \dots \}$, the distinct cosets are $H, 1+H,$ and $2+H$.

### **Cyclic Groups and Generators**
*   **Order of an element $O(a)$**: The smallest positive integer $n$ such that $a^n = e$ (the identity element).
*   **Generating Element (Generator)**: An element $a$ is a generator if every other element in the set can be represented purely as an integral power of $a$. 
*   **Cyclic Group**: Any group that contains at least one generating element. The order of a cyclic group is always equal to the order of its generating element.

### **Rings, Integral Domains, and Fields**
These are advanced algebraic systems defined over a non-empty set $R$ using two binary operations (typically denoted as $+$ and $\cdot$):
*   **Ring**: To be a ring, $(R, +)$ must be an **abelian group**, $(R, \cdot)$ must be a **semigroup**, and the operation $\cdot$ must be distributive over $+$. *Example:* $(Z, +, \times)$.
*   **Integral Domain**: A commutative ring that possesses a "unity" element and has **no zero divisors** (meaning if $a \cdot b = 0$, then either $a=0$ or $b=0$). *Examples:* $(Z, +, \times)$, $(Q, +, \times)$, and $(R, +, \times)$.
*   **Field**: The highest structure, where both $(R, +)$ and $(R, \cdot)$ are **abelian groups** (meaning inverses exist for all non-zero elements), and $\cdot$ distributes over $+$. *Examples:* $(R, +, \times)$ and $(Q, +, \times)$.
